Help & FAQ

Last Updated: May 24, 2025

General Questions

What is Donezo?

Donezo is a modern task management web application built with Django and styled with Tailwind CSS. It helps users organize and manage their tasks with a clean, intuitive interface.

What features does Donezo offer?

  • User authentication with email verification
  • Task creation, editing, and deletion
  • Task organization by due date (Today, Upcoming, Overdue)
  • Task labeling and filtering
  • Task completion tracking
  • Responsive design that works on all devices
  • Password strength validation

Is Donezo free to use?

Based on the codebase, Donezo appears to be freely available. There's no visible payment or subscription model implemented.

Account Management

How do I create an account?

You can register for an account by clicking the "REGISTER HERE" link on the login page, filling out the registration form with your name, email address, and password.

How secure is my password?

Donezo implements password strength validation to ensure you create a secure password. The application also uses proper security practices to store your credentials securely.

How do I change my email address?

  1. Log in to your account
  2. Go to the settings section
  3. Select the "Change Email" tab
  4. Enter your new email address
  5. You'll receive a verification email to confirm the change

How do I change my password?

  1. Log in to your account
  2. Go to the settings section
  3. Select the "Change Password" tab
  4. Enter your current password and your new password
  5. Confirm your new password and submit the form

What happens if I forget my password?

The application has a password recovery option. You can request a password reset link sent to your email address.

Task Management

How do I create a new task?

You can create a new task by clicking the task creation button and filling out the task form with details like title, description, due date, and labels.

How are tasks organized?

Tasks are organized into different sections:

  • Overdue tasks (past due date)
  • Today's tasks (due today)
  • Upcoming tasks (future due date) and tasks with no due date

How do I mark a task as complete?

You can mark a task as complete by checking the checkbox next to the task. The system will update the task's status accordingly.

Can I edit a task after creating it?

Yes, each task has an edit button that allows you to modify all task details after creation.

Privacy and Security

What information does Donezo collect?

As detailed in the Privacy Policy, Donezo collects:

  • Account information (name, email, password)
  • Usage data (tasks created, completed, and other app interactions)
  • Device information (device type, operating system, browser)

How is my data protected?

Donezo implements appropriate security measures to protect against unauthorized access, alteration, or destruction of data. However, no method of Internet transmission is 100% secure.

Who can see my tasks and personal information?

Your tasks and personal information are private and not shared with third parties except in limited circumstances as outlined in the Privacy Policy.

What are my rights regarding my data?

According to the Privacy Policy, you have the right to:

  • Access your personal information
  • Request correction of inaccurate information
  • Request deletion of your information
  • Object to processing of your information
  • Request restriction of processing
  • Request data portability

Technical Information

What technologies does Donezo use?

  • Backend: Python 3.13.2, Django 5.2.1, SQLite database
  • Frontend: Tailwind CSS 3.x, JavaScript
  • Development tools: Django Browser Reload, PostCSS

Can I run Donezo locally?

Yes, you can run Donezo locally by following the installation steps in the README:

  1. Clone the repository
  2. Create and activate a virtual environment
  3. Install Python dependencies
  4. Install Node.js dependencies for Tailwind CSS
  5. Run migrations
  6. Start the Tailwind CSS watcher
  7. Start the development server
  8. Access the application at http://127.0.0.1:8000/
